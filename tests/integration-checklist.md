# 실제 웨일 수동 확인

개인 데이터를 삭제하지 않고 새 테스트 프리셋으로 확인하세요.

- [ ] 확장앱 설치 후 사이드바 아이콘으로 열고 닫을 수 있다.
- [ ] 초기 화면에서 저장한 작업공간 목록과 생성 버튼을 확인할 수 있다.
- [ ] 새 작업공간에서 현재 웹 탭 목록을 자동으로 가져오고 내부 페이지는 제외한다.
- [ ] 링크 직접 추가를 누르면 주소 입력창이 나타난다.
- [ ] 이름·포함할 페이지·나란히 보기 변경 후 저장된다.
- [ ] 5개 작업공간, 10페이지 제한이 적용된다.
- [ ] 다른 프리셋을 열면 해당 URL 구성이 실행된다.
- [ ] 작업공간 열기를 누르면 별도 확인 없이 저장된 좌우 사이트가 실행된다.
- [ ] 나란히 보기 실패 시 일반 탭으로 자동 대체하고 안내한다.
- [ ] 확장앱 로드 뒤 연 듀얼탭의 좌우 주소가 자동으로 한 그룹에 담긴다.
- [ ] 확장앱 로드 전에 이미 열린 듀얼탭은 오른쪽 새로고침 뒤 다시 가져올 수 있다.
- [ ] 브라우저 재시작 후 사용자 프리셋이 유지된다.
- [ ] 카드 메뉴에서 수정·삭제가 동작하고, 삭제 시 추가 확인을 요구하지 않는다.
- [ ] 실패한 페이지만 재시도할 수 있다.
- [ ] 390px에서 가로 잘림 없이 버튼을 누를 수 있다.
- [ ] 생성·수정 창을 반복 열어도 이벤트·저장이 중복되지 않는다.
