# 실제 웨일 수동 확인

개인 데이터를 삭제하지 않고 새 테스트 프리셋으로 확인하세요.

- [ ] 확장앱 설치 후 사이드바 아이콘으로 열고 닫을 수 있다.
- [ ] 초기 화면에서 저장한 작업공간 목록과 생성 버튼을 확인할 수 있다.
- [ ] 새 작업공간에서 현재 웹 탭과 로컬 파일 탭 목록을 자동으로 가져오고 내부 페이지는 제외한다.
- [ ] 링크 직접 추가를 누르면 주소 입력창이 나타난다.
- [ ] 로컬 PDF의 file:/// 주소와 Windows 전체 경로를 직접 추가할 수 있고 파일명이 표시된다.
- [ ] 한글·공백·#·%가 포함된 파일 경로를 저장하고 다시 열면 PDF가 정상 표시된다.
- [ ] 로컬 PDF 작업공간을 닫아도 원래 열려 있던 PDF 탭은 유지된다.
- [ ] PDF가 왼쪽·오른쪽인 듀얼탭과 로컬 파일 두 개 듀얼탭을 다시 열면 일반탭 전환 안내 없이 좌우 문서가 표시된다.
- [ ] 복원한 파일 듀얼탭을 다시 저장해도 A/B 구성이 유지되고 작업공간 닫기로 양쪽을 닫을 수 있다.
- [ ] 이름과 포함할 페이지를 변경한 후 저장된다.
- [ ] 수정 화면에는 체크박스 대신 각 페이지의 ⋮ 메뉴가 있고, 휴지통 아이콘과 '작업공간에서 제거'가 표시된다.
- [ ] 제거 후 저장하면 해당 페이지만 빠지고, 저장하지 않고 닫으면 기존 구성이 유지된다.
- [ ] 듀얼탭 한쪽을 제거하면 다른 쪽은 일반탭으로 남는다.
- [ ] 메뉴에서 Escape를 누르면 수정 창은 유지되고 메뉴만 닫힌다.
- [ ] 모든 페이지를 제거하면 빈 목록 안내가 나타나며, 페이지를 추가하기 전에는 저장되지 않는다.
- [ ] 작업공간을 5개 넘게 만들거나 공유받아 저장할 수 있고, 작업공간당 10페이지 제한은 적용된다.
- [ ] 다른 프리셋을 열면 해당 URL 구성이 실행된다.
- [ ] 작업공간 열기를 누르면 별도 확인 없이 저장된 좌우 사이트가 실행된다.
- [ ] 열기 후 열린 페이지 수와 작업공간 닫기 버튼이 나타나며, 닫기를 누르면 그 작업공간으로 연 페이지만 닫힌다.
- [ ] 같은 주소로 미리 열린 탭과 다른 작업공간의 탭은 닫히지 않는다.
- [ ] 일반탭·듀얼탭, 중복으로 연 페이지, 다른 창으로 옮긴 페이지를 닫을 수 있고 이미 닫은 페이지는 건너뛴다.
- [ ] 사이드바를 다시 열어도 닫기를 사용할 수 있고, 닫은 뒤에도 저장된 작업공간 구성은 유지된다.
- [ ] 나란히 보기 실패 시 일반 탭으로 자동 대체하고 안내한다.
- [ ] 확장앱 로드 뒤 연 듀얼탭의 좌우 주소가 자동으로 한 그룹에 담긴다.
- [ ] 저장·수정 화면에서 이화여대·연세대·충남대가 각각 한 줄로 표시되고 앞 두 줄에만 듀얼탭 A/B가 붙는다.
- [ ] '다음 페이지와 나란히 보기' 또는 수동 듀얼탭 설정 버튼이 표시되지 않는다.
- [ ] 듀얼탭 한쪽을 해제해도 다른 쪽은 선택되어 있고, A/B 표시가 사라지며 일반 페이지로 저장된다. 저장 전 두 쪽을 다시 선택하면 듀얼탭으로 복원된다.
- [ ] 저장한 카드의 듀얼탭 묶음을 확인하고 다시 열면 한 쌍으로 실행된다.
- [ ] 처음 가져올 때 10페이지 경계에서 듀얼탭을 임의로 나누지 않는다. 이후 사용자가 한쪽만 선택해 10페이지로 저장할 수 있고, 11번째 선택은 차단된다.
- [ ] 확장앱 로드 전에 이미 열린 듀얼탭도 웹페이지 새로고침 없이 양쪽을 가져온다.
- [ ] 왼쪽·오른쪽·일반탭 중 어디를 클릭했든 저장 목록의 좌우 순서가 같다.
- [ ] 브라우저 재시작 후 사용자 프리셋이 유지된다.
- [ ] 카드 메뉴에서 수정·삭제가 동작하고, 삭제 시 추가 확인을 요구하지 않는다.
- [ ] 카드 제목·빈 공간을 잡아 위아래로 드래그하면 표시된 선 위치로 이동한다.
- [ ] 화면 끝에서 드래그하면 목록이 자동 스크롤되고, Escape로 취소하면 원래 순서가 유지된다.
- [ ] 사이드바를 다시 열거나 작업공간을 수정해도 저장한 순서가 유지된다.
- [ ] 실패한 페이지만 재시도할 수 있다.
- [ ] 390px에서 가로 잘림 없이 버튼을 누를 수 있다.
- [ ] 생성·수정 창을 반복 열어도 이벤트·저장이 중복되지 않는다.
- [ ] 카드 아래 작업공간 공유 버튼에서 웹페이지와 제외될 로컬 파일을 미리 확인한다.
- [ ] 공유하기·받기 모두 동의 체크 전에는 버튼이 비활성화되고 Enter를 눌러도 인증·서버 요청이 나가지 않는다.
- [ ] 동의 후 실행하면 정상 공유·받기가 되고, 동의하지 않은 채 닫아도 로컬 작업공간은 계속 사용할 수 있다.
- [ ] 로컬 파일만 있으면 공유 버튼이 비활성화되고 Firebase로 전송하지 않는다.
- [ ] 공유 코드 복사 후 모달 위에 성공 토스트가 뜨며, 복사 실패 시 수동 복사할 수 있다.
- [ ] 다른 웨일 프로필에서 코드를 받아 목록 확인 뒤 저장 또는 바로 열기를 할 수 있다.
- [ ] 받은 미리보기에서는 코드와 듀얼탭 A/B 표시가 숨겨지고 실제 실행은 듀얼탭을 보존한다.
- [ ] 파일 제외로 한쪽만 남은 듀얼탭은 일반탭으로 전달되며 원본 작업공간은 유지된다.
- [ ] 공유 문서에는 로컬 파일 경로·이름·인증 토큰·브라우저 탭 ID가 포함되지 않는다.
- [ ] 무료 사용 한도/네트워크 오류로 공유가 실패해도 로컬 작업공간 저장·열기는 유지된다.
