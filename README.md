# ME:WE — 네이버 웨일 작업공간

열어둔 학습 페이지를 작업공간으로 저장하고, 필요할 때 한 번에 다시 여는 네이버 웨일 사이드바 확장앱입니다.

## 스토어 제출 준비

[제출 준비 안내](docs/START-HERE.md)에 스토어 문구, 심사 설명, 운영 절차와 남은 작업을 모았습니다. [개인정보 처리방침 초안](PRIVACY.md)은 앱 상단 **앱 정보**에서도 확인할 수 있습니다. 문의 및 삭제 요청: h33jin.jeong@gmail.com. 개인정보 처리방침은 정식 시행 전 검토본이며, 웹페이지 배포와 스토어 제출은 아직 진행하지 않았습니다.

## 설치

1. 이 저장소의 **Code → Download ZIP**을 선택하고 압축을 풉니다. 또는 저장소를 클론합니다.
2. 네이버 웨일에서 `whale://extensions`를 엽니다.
3. 개발자 모드를 켜고 **압축해제된 확장앱 설치**를 선택합니다.
4. 압축을 푼 폴더 중 `manifest.json`이 있는 폴더를 선택합니다.
5. 사이드바에서 ME:WE를 엽니다. 설치한 코드를 업데이트한 경우 확장앱 관리 화면에서 새로고침하고 사이드바를 다시 엽니다.

별도 빌드 과정 없이 설치할 수 있습니다. 개인 작업공간은 로컬에서 동작하고, 공유 기능은 Firebase 초기 설정이 필요합니다. [Firebase 설정 안내](FIREBASE_SETUP.md)를 참고하세요.

## 화면 구성

기본 배경은 `#FFFFFF`입니다. 저장 버튼·체크박스·초록색 강조에는 이화그린(`#075B46`), 듀얼탭 구분에는 블루·라벤더, 목록과 보조 버튼에는 밝은 회색을 사용합니다. 작업공간별 페이지를 한 줄씩 보여주고, 듀얼탭의 좌우 페이지는 A/B로 구분합니다. 별도의 드래그 손잡이 없이 카드 자체를 잡아 순서를 바꿀 수 있습니다.

## 사용

- **지금 작업공간 저장** 또는 **새 작업공간**: 현재 창의 웹 탭과 로컬 파일 탭을 자동으로 불러옵니다. 이름을 입력하고 필요한 페이지를 선택한 뒤 저장합니다. 주소를 직접 넣으려면 **링크 직접 추가**를 누릅니다.
- **로컬 파일 추가**: 브라우저에서 연 PDF 등의 `file:///C:/자료/강의.pdf` 주소 또는 `C:\자료\강의.pdf` 전체 경로를 입력할 수 있습니다. 탐색기에서 복사한 따옴표 포함 경로도 지원하며 목록에는 파일명이 표시됩니다. 파일 자체를 복사하거나 업로드하지 않고 경로만 저장하므로, 파일을 옮기거나 삭제하면 다시 열 수 없습니다.
- 모든 페이지는 각각 한 줄로 표시됩니다. 듀얼탭의 왼쪽 페이지에는 **듀얼탭 A**, 오른쪽 페이지에는 **듀얼탭 B**가 붙습니다. 두 페이지는 함께 선택·저장되며 다시 열 때 좌우 순서가 유지됩니다.
- **작업공간 열기**: 저장된 페이지를 바로 엽니다. 나란히 보기로 저장한 두 페이지는 웨일 분할 화면으로 시도하며, 실패하면 각 페이지를 일반 탭으로 엽니다.
- **작업공간 닫기**: 이 앱의 열기 버튼으로 연 페이지가 있으면 카드에 표시됩니다. 해당 작업공간으로 연 일반탭과 듀얼탭만 닫으며, 저장한 작업공간은 유지됩니다. 여러 번 열었다면 아직 열려 있는 실행분을 모두 닫습니다. 원래 열려 있던 같은 주소의 탭은 닫지 않습니다.
- 열린 페이지 추적은 현재 브라우저 실행 동안 유지되며 사이드바를 닫았다 다시 열어도 이어집니다. 브라우저 재시작이나 확장앱 다시 로드 전의 탭은 닫기 대상으로 삼지 않습니다. 다른 페이지를 수동으로 합친 듀얼탭은 함께 닫히지 않도록 남겨두고 안내합니다.
- 카드의 `⋮` 메뉴에서 수정하거나 삭제할 수 있습니다. 삭제는 원본 웹페이지에 영향을 주지 않습니다.
- 작업공간 수정 화면에서는 각 페이지의 `⋮ → 작업공간에서 제거`로 페이지를 뺄 수 있습니다. **저장**을 누르면 반영되며, 열려 있는 브라우저 탭이나 원본 파일은 닫거나 삭제하지 않습니다. 듀얼탭 한쪽을 제거하면 남은 페이지는 일반탭으로 저장됩니다. 새 작업공간을 만들 때는 체크박스로 포함할 페이지를 선택합니다.
- 카드의 제목이나 빈 공간을 잡고 위아래로 드래그하면 작업공간 순서를 바꿀 수 있습니다. 초록색 선 위치에 놓으면 자동 저장됩니다. 카드에 키보드 초점을 둔 뒤 `Alt + ↑/↓`로도 이동할 수 있습니다.

## 작업공간 공유

- 카드 아래의 **작업공간 공유** 버튼에서 사이트명과 URL, 제외되는 로컬 파일을 확인한 뒤 **공유 코드 복사**를 누릅니다. 로컬 파일은 전송 전에 제외되며, 한쪽만 남은 듀얼탭은 일반탭으로 전달됩니다. 원본 작업공간은 바뀌지 않습니다.
- 공유 코드 형식은 `ABCD-EFGH-2345`처럼 12자리입니다. 무작위 코드로 저장 시점의 복사본을 전달하며, 코드를 아는 사용자는 목록을 조회할 수 있습니다. 기본 유효기간은 7일입니다.
- **공유 작업공간 받기 → 코드 입력 → 작업공간 확인**에서 전달받은 페이지를 확인합니다. **저장**은 내 작업공간에 독립적인 복사본을 추가하고, **바로 열기**는 저장하지 않고 바로 실행합니다. 바로 열기로 연 페이지는 저장된 작업공간 카드의 닫기 대상에 포함되지 않습니다.
- 미리보기에는 코드나 듀얼탭 내부 표시를 반복하지 않습니다. 페이지 순서와 온전한 듀얼탭 구성은 내부적으로 유지됩니다. 미리보기는 최대 15분 동안 유효합니다.
- 온라인 PDF도 웹 주소라면 포함할 수 있습니다. 로그인 상태나 문서 열람 권한은 전달되지 않습니다. 로컬 파일만 있는 작업공간은 공유 코드를 만들 수 없습니다.

## 데이터 저장

작업공간은 웨일 확장앱의 로컬 저장소에 저장됩니다. 기존 설치의 작업공간은 유지됩니다. 새 설치에서는 예시 작업공간을 자동으로 만들지 않습니다.

열기 버튼으로 생성한 탭 ID는 `storage.session`에 작업공간별로 보관합니다. 주소 일치 여부로 닫을 대상을 추측하지 않습니다.

| 권한 | 사용 목적 |
| --- | --- |
| `storage` | 작업공간의 이름과 페이지 구성 저장 |
| `tabs` | 열린 페이지의 제목·주소 읽기 및 저장한 페이지 열기 |
| `debugger` | `getTargets`로 일반 탭 조회에서 빠진 듀얼탭 페이지의 ID 확인 |
| `clipboardWrite` | 사용자가 누른 공유 코드 복사 버튼 처리 |
| Firebase API 3개 도메인 | 익명 인증, 인증 갱신, 공유 작업공간 저장·조회 |

`debugger`는 브라우저가 디버깅 접근을 허용하는 권한입니다. 이 앱은 `getTargets`로 열린 페이지 목록만 조회하며, 디버거 연결(`attach`)이나 페이지에 명령 보내기(`sendCommand`)는 사용하지 않습니다. 가져온 ID를 `tabs.get`으로 확인해 현재 창의 같은 탭 위치에 있는 두 페이지만 묶습니다. 0.2.3으로 업데이트할 때 확장앱 새로고침과 추가 권한 확인이 필요할 수 있습니다.

개인 작업공간은 자동 업로드하지 않습니다. **공유 코드 복사**를 누를 때만 작업공간 이름·공유 가능한 웹페이지 제목/URL/순서/듀얼탭 구성, 익명 사용자 ID와 생성·만료시각을 Firebase에 저장합니다. 제외된 파일 이름과 경로, 브라우저 탭 ID는 전송하지 않습니다. 로그인 세션·쿠키·파일 내용도 전송하지 않습니다. 페이지를 열면 해당 사이트에 직접 접속합니다.

Firebase 익명 인증 토큰은 확장앱 로컬 저장소에 보관하며 공유 문서에 포함하지 않습니다. REST API와 Firebase ID 토큰을 사용하고 Firestore 보안 규칙을 적용합니다. 외부 JavaScript를 실행하거나 서비스 계정 키를 사용하지 않습니다.

Spark 무료 구성으로 Cloud Functions·Cloud Storage·유료 TTL 삭제는 사용하지 않습니다. 만료는 보안 규칙이 조회를 차단하는 방식이며, 만료 문서 자체는 자동 삭제되지 않습니다. 관리자 콘솔에서 정리할 수 있습니다. 익명 인증과 규칙만으로 강력한 IP별 요청 제한을 제공하지는 않습니다. 무료 한도 도달 시 공유 요청에 오류를 안내하며 기존 개인 작업공간은 유지됩니다.

## 범위와 검증

Node.js 20 이상에서 `npm test`를 실행하면 데이터 검증, 저장, 실행 실패 처리 테스트를 확인할 수 있습니다. 추가 패키지 설치는 필요하지 않습니다.

공유 보안 규칙은 `tests/sharing-rules.test.js`, 실제 웨일 공유 흐름은 `tests/native-sharing.cjs`에서 확인합니다. 둘 다 `127.0.0.1:8787`의 Firestore 에뮬레이터와 `demo-mewe` 프로젝트를 사용합니다. 실행 방법은 [Firebase 설정 안내](FIREBASE_SETUP.md)에 있습니다. 네이티브 테스트는 익명 인증 응답만 모의하며, 실제 REST 저장·조회와 Firestore 규칙 및 두 격리된 웨일 프로필의 UI를 검증합니다. 운영 Firebase에 대한 최종 확인은 규칙 게시 후 진행해야 합니다.

듀얼탭 UI 테스트는 `tests/ui-dual.cjs`에 있습니다. Playwright를 사용할 수 있는 환경에서 `node tests/ui-dual.cjs`로 실행합니다. 기본 브라우저는 Windows의 Edge이며 `MEWE_BROWSER_EXE`로 실행 파일을 지정할 수 있습니다. 이 테스트는 웨일 탭 정보를 모의해 세 페이지의 개별 표시, A/B 배지, 함께 선택, 저장, 수정과 320px 화면을 확인합니다.

실제 웨일 검증은 `node tests/native-capture.cjs`로 실행합니다. 임시 프로필과 로컬 테스트 페이지만 사용합니다. 웨일 5.39.412.57에서 이화여대·연세대 듀얼탭과 충남대 일반탭을 재현해, 탐색 기록 없이 일반탭·왼쪽·오른쪽을 각각 활성화한 상태에서도 세 페이지의 순서와 듀얼탭 구성이 유지됨을 확인했습니다.

작업공간 순서 변경은 `node tests/native-reorder.cjs`로 검증합니다. 격리된 웨일 프로필에서 실제 드래그와 키보드 이동, 자동 스크롤, 취소, 새로고침 후 순서 유지, 수정 메뉴와 듀얼탭 데이터 보존을 확인합니다.

닫기는 `node tests/native-close.cjs`로 검증합니다. 같은 주소의 기존 탭·다른 작업공간 보존, 듀얼탭 양쪽 닫기, 중복 실행, 수동으로 닫은 탭, 다른 창으로 옮긴 탭, 사이드바 새로고침 후 닫기를 실제 웨일에서 확인합니다.

로컬 파일은 `node tests/native-files.cjs`로 검증합니다. 격리된 웨일 프로필에서 PDF 탭 자동 수집, 한글·공백·특수문자가 포함된 Windows 경로 입력, 저장 후 실제 PDF 표시, 닫을 때 기존 PDF 탭 보존을 확인합니다.

파일을 포함한 듀얼탭은 `node tests/native-file-dual.cjs`로 검증합니다. PDF가 왼쪽 또는 오른쪽인 웹페이지 조합, 로컬 파일 두 개 조합, 웹페이지 두 개 조합에서 같은 네이티브 탭의 좌우 복원, PDF 뷰어의 실제 로드, 다시 수집한 듀얼탭 구성, 양쪽 닫기를 확인합니다. 확장앱 내부 준비 페이지로 듀얼탭을 먼저 만든 뒤 파일 주소를 탭 API로 엽니다.

웨일의 공개 분할 화면 링크를 이용한 나란히 보기는 브라우저 버전과 설정에 따라 다르게 동작할 수 있습니다. 실패 시 일반 탭으로 자동 전환합니다. 설치 후 확인할 항목은 [수동 검증 목록](tests/integration-checklist.md)에 정리했습니다.
