# ME:WE

**열어둔 페이지를 작업공간으로 저장하고, 필요할 때 다시 열어보세요.**

네이버 웨일의 사이드바에서 학습 페이지를 모아두고, 듀얼탭 구성까지 다시 여는 작업공간 앱입니다.

운영팀 **ewhale** · 개발자 **정희진** · 현재 버전 **0.3.0** · **웨일스토어 출시 준비 중**

[사용 가이드](docs/user-guide.md) · [개인정보 안내](PRIVACY.md) · [변경 이력](CHANGELOG.md) · [개발 문서](docs/development.md)

## 주요 기능

| 기능 | 할 수 있는 일 |
| --- | --- |
| 작업공간 저장 | 현재 창의 페이지를 선택해 이름을 붙여 저장 |
| 듀얼탭 복원 | 좌우 페이지를 A/B로 구분하고 나란히 다시 열기 |
| 열기·닫기 | 저장한 페이지를 열고, 앱으로 연 탭만 함께 닫기 |
| 수정·정렬 | 페이지 추가·제거, 이름 변경, 카드 드래그로 순서 변경 |
| 로컬 파일 | 내 컴퓨터의 PDF 등 파일 주소 저장 |
| 코드 공유 | 웹페이지 목록을 12자리 코드로 전달하고 내 작업공간에 가져오기 |

작업공간 개수에는 앱에서 정한 제한이 없습니다. 작업공간 하나에는 최대 10페이지를 저장하며, 브라우저 저장 용량의 제한은 적용됩니다.

## 설치하기

스토어 공개 전에는 개발자 모드로 설치할 수 있습니다.

**[설치용 앱 ZIP 받기](https://github.com/heejin0316/mewe-naver-whale/raw/refs/heads/main/delivery/MEWE-0.3.0.zip)** · [아이콘·스크린샷·제출 안내](delivery/) · [최종 검증 결과](docs/final-review.md)

1. 위의 **설치용 앱 ZIP**을 내려받아 압축을 풉니다.
2. 네이버 웨일 주소창에 `whale://extensions`를 입력합니다.
3. **개발자 모드 → 압축해제된 확장앱 설치**를 누릅니다.
4. 압축을 푼 폴더 중 **`manifest.json`이 있는 폴더**를 선택합니다.
5. 사이드바에서 **ME:WE**를 엽니다.

팀원 설치와 스토어 업로드에는 동일한 앱 ZIP을 사용합니다. 저장소의 **Code → Download ZIP**은 개발 소스 전체이므로 스토어에 제출하지 않습니다. 현재 패키지는 검증을 마친 **제출 후보**이며, 심사 요청 전 [운영 점검](docs/release-checklist.md)을 확인하세요.

별도 빌드나 npm 설치가 필요하지 않습니다. **일반 사용자는 Firebase를 설정할 필요가 없습니다.** 공유 기능은 앱에 연결된 운영 서비스를 사용합니다.

업데이트할 때는 기존 설치 폴더의 파일을 갱신하고 확장앱 관리 화면에서 **새로고침**하세요. 작업공간을 유지하려면 확장앱을 삭제하지 마세요. 설치한 폴더는 이동하거나 삭제하지 않는 것이 좋습니다.

## 빠르게 사용하기

1. 필요한 페이지를 열고 **지금 작업공간 저장**을 누릅니다.
2. 작업공간 이름과 포함할 페이지를 확인한 뒤 **저장**합니다.
3. 카드의 **작업공간 열기**로 이어서 작업하고 **작업공간 닫기**로 정리합니다.
4. 함께 볼 웹페이지는 **작업공간 공유**, 받은 코드는 **공유 작업공간 받기**를 사용합니다.

링크 입력 후 `Enter`로 추가하고, 저장 버튼에 초점이 옮겨진 뒤 다시 `Enter`로 저장할 수 있습니다. 이름이 비어 있으면 이름부터 입력합니다. 카드 순서는 드래그하거나 카드에 초점을 두고 `Alt + ↑/↓`로 바꿉니다.

## 데이터와 알아둘 점

- 개인 작업공간은 기기에 저장하며 자동으로 서버에 업로드하지 않습니다.
- 공유 시 미리보기의 작업공간 이름·웹페이지 정보 등을 서버에 저장합니다. 주소에 개인정보나 비공개 문서 접근 정보가 포함되어 있는지 확인하세요.
- 공유 코드는 **7일간 유효**합니다. 담당자가 만료 문서를 매주 정리하고 생성 후 **최대 14일 이내 삭제**합니다. 서버 자동 삭제와 앱 내 철회 기능은 없으며, 삭제 요청은 문의 이메일로 받습니다.
- 공유 기능 최초 이용 시 개인정보 수집·이용과 미국으로의 인증 정보 이전에 동의하면, 같은 브라우저의 공유하기·공유받기에 공통 적용합니다. 앱 정보에서 공유 사용을 중지할 수 있습니다. 동의하지 않아도 개인 작업공간 기능은 사용할 수 있습니다.
- 로컬 파일은 **경로만 저장**하며 공유에서 제외합니다. 파일을 이동·삭제하면 열 수 없습니다. 로그인 상태와 문서 열람 권한도 전달되지 않습니다.
- 듀얼탭 복원은 웨일 버전·설정에 영향을 받습니다. 실패하면 일반 탭으로 열고 안내합니다.
- 닫기는 앱이 이번 실행에서 추적한 탭에 적용됩니다. 브라우저 재시작·확장앱 새로고침 전의 탭과 공유 미리보기에서 **바로 열기**로 연 탭은 저장된 카드의 닫기 대상이 아닙니다.

처리 항목과 삭제 방법은 [개인정보 처리방침](PRIVACY.md)을 확인하세요. 시행일은 2026-10-12이며, Firestore 저장 위치는 서울입니다. 실제 삭제·요청 처리는 [운영 절차](docs/operations.md)를 따릅니다.
