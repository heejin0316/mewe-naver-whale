팀원 여러분, ME:WE 최종 확인용 파일 전달드립니다!
네이버 웨일에서 아래 순서대로 설치해 주세요.

[처음 설치한다면]
1. MEWE-0.3.1.zip을 내려받아 압축을 풀어 주세요.
2. 압축을 푼 앱 폴더를 계속 보관할 위치에 두세요.
3. 웨일 주소창에 whale://extensions 를 입력해 주세요.
4. 개발자 모드를 켜고 '압축해제된 확장앱 설치'를 눌러 주세요.
5. manifest.json 파일이 들어 있는 앱 폴더를 선택해 주세요.
6. 사이드바에서 ME:WE 아이콘을 열어 사용해 주세요.

[이전 버전을 설치했다면]
기존 확장앱을 삭제하지 마세요. 저장한 탭 모음이 지워질 수 있습니다.
새 ZIP의 내용물을 기존 설치 폴더에 덮어쓰고, whale://extensions 에서
ME:WE 새로고침(↻)을 누른 뒤 사이드바를 다시 열어 주세요.
붙여넣기 기능에 필요한 클립보드 읽기 권한 안내가 뜨면 확인해 주세요.
설치 폴더를 잊었다면 삭제·재설치하지 말고 개발자에게 문의해 주세요.

[짧게 확인해 주세요]
□ 탭 저장하기에서 새 탭 모음 만들기 또는 기존 탭 모음 뒤에 추가
□ 한 번에 닫기 → 취소하면 유지, 모두 닫기를 누르면 앱이 연 탭 닫기
□ 공유 코드 붙여넣기 → 탭 불러오기 → 카드 확인 후 저장 또는 바로 열기
□ 일반 페이지·듀얼탭 저장 → 열기 → 앱으로 연 탭 닫기
□ 듀얼탭 한쪽 해제 시 다른 쪽은 선택된 채 일반 페이지로 저장
□ 수정·Enter로 링크 추가·순서 변경, 삭제 취소 시 원본 유지
□ 수정 중 사이드바를 닫았다 열 때 원치 않는 확인창이 뜨지 않는지
□ 새 공유 코드를 다른 사람이 받아 저장·열기, 다음 공유 때 동의 생략

공유 코드는 7일 후 만료되므로 예전 고정 코드 대신 새 코드를 써 주세요.
개인정보 없는 공개 웹페이지로 시험해 주세요.
공유 기능 최초 이용 시 동의가 필요하며 Firebase 설정·별도 회원가입은 필요하지 않습니다.
