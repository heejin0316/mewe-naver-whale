기기에 저장하는 정보

탭 모음 이름, 페이지 제목·주소·순서, 듀얼탭 구성, 식별자 및 생성·수정 시각은 확장앱의 로컬 저장소에 저장합니다. 로컬 파일은 파일 내용 대신 파일 경로와 제목만 저장합니다. 개인 탭 모음은 자동으로 서버에 업로드하지 않습니다.

열어둔 페이지를 가져올 때 탭 제목·주소와 ID를 읽습니다. 듀얼탭 양쪽을 확인하기 위해 debugger.getTargets로 탭 ID를 조회하지만 디버거를 연결하거나 명령을 보내지는 않습니다. 앱이 연 탭의 ID는 해당 탭만 닫기 위한 용도로 세션 저장소에 보관합니다.

공유 동의 항목, 동의 내용 버전과 동의 시각을 이 브라우저의 로컬 저장소에 보관하여 반복 동의를 생략합니다. 동의 기록은 서버로 전송하지 않으며 앱 정보에서 공유 사용을 중지하거나 앱을 제거하면 삭제됩니다.

공유 기능을 사용하면 익명 인증 ID와 인증·갱신 토큰을 로컬에 보관합니다. 토큰을 공유 문서에는 넣지 않습니다. 공유받은 미리보기는 세션 저장소에 최대 10건 보관하며, 최대 15분 후 사용할 수 없게 됩니다. 유효기간 경과와 저장소에서의 즉시 삭제는 동일하지 않습니다.

공유 코드 입력 화면에서 ‘붙여넣기’를 누를 때만 클립보드의 텍스트를 읽어 이 기기의 코드 입력란에 표시합니다. 붙여넣기만으로 서버에 요청하지 않습니다. ‘탭 불러오기’를 누르면 코드 형식을 검사하고 정규화한 공유 코드만 조회에 사용하며, 클립보드의 다른 내용을 서버에 보내지 않습니다. ‘공유 코드 복사’를 누르면 생성된 코드를 클립보드에 씁니다.

공유할 때 서버로 전송하는 정보

공유 코드 복사를 누르면 미리보기에 표시된 탭 모음 이름과 공유 가능한 웹페이지 제목·URL·순서·듀얼탭 구성·페이지 식별자, 익명 사용자 ID, 생성·만료 시각 및 데이터 형식 버전을 Google Firebase Cloud Firestore에 저장합니다. 목적은 공유 코드 생성과 해당 탭 모음의 전달입니다.

로컬 파일의 이름·경로·내용과 브라우저 탭 ID는 공유 문서에서 제외합니다. 쿠키, 웹사이트 로그인 세션, 페이지 본문을 수집해 전송하지 않습니다. 다만 웹 주소 자체에는 검색어, 개인 식별 정보 또는 문서 접근 토큰이 포함될 수 있으므로 공유 전에 주소를 확인해야 합니다.

공유와 받기는 선택 기능입니다. 이를 사용하지 않아도 개인 탭 모음을 저장하고 다시 열 수 있습니다. 공유 기능을 처음 이용할 때 개인정보 수집·이용과 국외 이전에 각각 동의한 뒤 실행 버튼을 누르면 동의 기록을 저장하고 Firebase 익명 인증을 사용합니다. 체크만 하고 닫으면 동의 기록이나 인증 요청을 만들지 않습니다. 같은 브라우저에서는 공유하기·공유받기에 동의를 공통 적용하며, 동의 범위 변경·기록 초기화 또는 다른 브라우저에서 이용할 때는 다시 동의를 받습니다. 이름·이메일·비밀번호를 입력하는 별도 회원가입을 요구하지 않습니다.

공유 범위와 유효기간

공유 코드를 알고 있는 사람은 앱을 통해 유효기간 안에 공유된 페이지 목록을 확인할 수 있습니다. 코드 소지는 원본 웹사이트의 로그인·열람 권한을 대신하지 않습니다. 공유 유효기간은 생성 시점부터 7일입니다.

정상 생성한 공유 코드는 7일 후 조회가 차단됩니다. 코드 만료 즉시 문서가 삭제되는 것은 아닙니다. 담당자 정희진이 만료 자료를 매주 정리하며 공유 문서는 생성 후 최대 14일 이내에 운영 데이터베이스에서 삭제합니다. 현재 서버의 자동 삭제 작업은 사용하지 않습니다.

저장한 탭 모음을 수정·삭제하거나 앱을 제거해도 이미 생성한 서버 공유본은 삭제되지 않습니다. 현재 앱에는 공유본 삭제·중단 버튼이 없습니다. 삭제·처리 정지는 문의 이메일로 요청할 수 있습니다. 받는 사람이 이미 저장한 복사본까지 원격으로 회수할 수는 없습니다.

외부 서비스 및 처리 위치

Google Firebase의 Authentication은 익명 인증을, Cloud Firestore는 공유 정보 저장·조회를 담당합니다. Firebase 인증 서비스는 부정 사용 방지를 위해 IP 주소와 브라우저 정보 등을 처리할 수 있습니다. 별도의 광고·사용 분석 SDK는 앱에 포함하지 않습니다.

공유 문서를 저장하는 Cloud Firestore 데이터베이스의 설정 위치는 대한민국 서울(asia-northeast3)입니다. Firebase Authentication은 이 설정과 별개로 미국에서 처리됩니다.

인증 정보의 국외 처리 수탁자는 Google LLC(Firebase)이며, 이전 국가는 미국입니다. 공유 생성 또는 코드 확인 시 HTTPS 통신으로 임시 사용자 ID, 인증·갱신 토큰, IP 주소 및 브라우저 정보가 처리됩니다. 목적은 요청자 인증, 공유 서비스 제공 및 부정 사용 방지입니다. Google의 문의 창구는 아래 Firebase 지원 링크에서 확인할 수 있습니다.

익명 인증 계정은 공유 인증 유지 기간 동안 보관하며, 이용 종료·동의 철회·계정 삭제를 요청하면 필요한 본인 확인 후 삭제 처리합니다. 앱 삭제만으로 서버 인증 계정이 삭제되지는 않습니다. Firebase 안내에 따르면 인증 IP 로그는 수 주 보관되고 계정 삭제 후 인증 정보는 운영·백업 시스템에서 최대 180일 이내 제거됩니다. 이 공급자 보관 기간은 ME:WE 공유 문서의 최대 14일 보관 기간과 다릅니다.

국외 처리를 거부하려면 공유 기능에 동의하지 않으면 됩니다. 거부 시 공유 생성·코드 확인은 이용할 수 없지만 개인 탭 모음 저장·수정·열기는 계속 사용할 수 있습니다. 이미 동의한 경우 앱 정보의 ‘이 기기에서 공유 사용 중지’로 동의 기록과 받은 미리보기를 삭제하고 추가 공유 요청을 중단할 수 있습니다. 이는 이미 전송된 서버 자료나 인증 계정을 삭제하는 절차가 아니므로, 서버 정보 삭제·처리 정지·동의 철회는 담당자에게 요청할 수 있습니다. 웹페이지를 열면 해당 사이트에 직접 접속하며 그 사이트의 개인정보 처리방침이 적용됩니다.

Firebase 개인정보 및 보안 안내

Firebase 지원·문의

보관과 삭제

개인 탭 모음은 사용자가 ‘저장한 탭 관리’에서 삭제할 수 있습니다. 삭제는 브라우저 탭이나 원본 파일을 삭제하지 않습니다. 확장앱 제거 시 브라우저가 앱의 로컬 저장소를 제거하며, 이것은 Firebase의 공유 문서나 익명 계정 삭제를 뜻하지 않습니다.

탭 실행 추적용 세션 정보는 브라우저 종료 또는 확장앱 다시 로드 시 초기화됩니다. 서버 공유 문서와 익명 계정은 각각 별도 삭제가 필요합니다.

문의 시 이메일 주소와 문의 내용·첨부 자료를 문의 응대와 권리 행사 처리 목적으로 이용합니다. 메일과 개인 정보가 포함된 처리 기록은 처리 완료 후 30일 이내 삭제하며, 삭제 시 휴지통의 사본도 함께 정리합니다. 문의에 불필요한 개인 정보는 보내지 마세요.

삭제 대상 전자 기록은 운영 저장소에서 삭제해 복구·재사용하지 않도록 처리합니다. 별도의 민감정보·고유식별정보 입력을 요구하지 않으며 브라우저 쿠키나 웹사이트 로그인 정보도 수집하지 않습니다. 서비스 제공 과정에서 Google이 처리하는 로그·백업은 위 공급자 정책을 따릅니다.

보호 조치와 변경 안내

서버 통신에는 HTTPS와 Firebase 인증 토큰을 사용합니다. Firestore 규칙은 전체 목록 조회와 공유본 수정을 차단하고, 유효기간 및 생성 데이터 형식을 확인합니다. 공유 코드와 주소를 전달할 상대는 신중하게 선택해 주세요.

이 안내는 현재 0.3.1 구현을 기준으로 작성했습니다. 2026년 10월 23일에는 화면의 ‘탭 모음’ 명칭과 사용자가 요청한 클립보드 붙여넣기 처리를 반영했습니다. 서버로 보내는 정보·처리 목적·보관 기간과 기존 공유 동의 범위는 동일합니다. 내용이 바뀌면 앱 정보와 공개 개인정보 페이지에 변경 내용·시행일을 안내하며, 처리 목적·항목·보관 방법이 변경되면 실제 구현과 필요한 동의 절차도 함께 갱신합니다.
