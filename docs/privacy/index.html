기기에 저장하는 정보

작업공간 이름, 페이지 제목·주소·순서, 듀얼탭 구성, 식별자 및 생성·수정 시각은 확장앱의 로컬 저장소에 저장합니다. 로컬 파일은 파일 내용 대신 파일 경로와 제목만 저장합니다. 개인 작업공간은 자동으로 서버에 업로드하지 않습니다.

열어둔 페이지를 가져올 때 탭 제목·주소와 ID를 읽습니다. 듀얼탭 양쪽을 확인하기 위해 debugger.getTargets로 탭 ID를 조회하지만 디버거를 연결하거나 명령을 보내지는 않습니다. 앱이 연 탭의 ID는 해당 탭만 닫기 위한 용도로 세션 저장소에 보관합니다.

공유 기능을 사용하면 익명 인증 ID와 인증·갱신 토큰을 로컬에 보관합니다. 토큰을 공유 문서에는 넣지 않습니다. 공유받은 미리보기는 세션 저장소에 최대 10건 보관하며, 최대 15분 후 사용할 수 없게 됩니다. 유효기간 경과와 저장소에서의 즉시 삭제는 동일하지 않습니다.

공유할 때 서버로 전송하는 정보

공유 코드 복사를 누르면 미리보기에 표시된 작업공간 이름과 공유 가능한 웹페이지 제목·URL·순서·듀얼탭 구성·페이지 식별자, 익명 사용자 ID, 생성·만료 시각 및 데이터 형식 버전을 Google Firebase Cloud Firestore에 저장합니다. 목적은 공유 코드 생성과 해당 작업공간의 전달입니다.

로컬 파일의 이름·경로·내용과 브라우저 탭 ID는 공유 문서에서 제외합니다. 쿠키, 웹사이트 로그인 세션, 페이지 본문을 수집해 전송하지 않습니다. 다만 웹 주소 자체에는 검색어, 개인 식별 정보 또는 문서 접근 토큰이 포함될 수 있으므로 공유 전에 주소를 확인해야 합니다.

공유와 받기는 선택 기능입니다. 이를 사용하지 않아도 개인 작업공간을 저장하고 다시 열 수 있습니다. 공유 코드 생성 또는 코드 확인 시 Firebase 익명 인증을 사용하며 이름·이메일·비밀번호를 입력하는 별도 회원가입을 요구하지 않습니다.

공유 범위와 유효기간

공유 코드를 알고 있는 사람은 앱을 통해 유효기간 안에 공유된 페이지 목록을 확인할 수 있습니다. 코드 소지는 원본 웹사이트의 로그인·열람 권한을 대신하지 않습니다. 공유 유효기간은 생성 시점부터 7일입니다.

7일 후에는 서버 규칙으로 조회를 차단합니다. 현재 만료 문서의 자동 삭제 기능은 없으며 관리자 삭제 전까지 서버에 남습니다. 실제 삭제 주기와 최대 보관 기간은 공개 전 확정 사항입니다. 7일 후 자동 삭제되는 서비스로 안내하지 않습니다.

내 작업공간을 수정·삭제하거나 앱을 제거해도 이미 생성한 서버 공유본은 삭제되지 않습니다. 현재 앱에는 공유본 삭제·중단 버튼이 없습니다. 삭제·처리 정지는 문의 이메일로 요청할 수 있습니다. 받는 사람이 이미 저장한 복사본까지 원격으로 회수할 수는 없습니다.

외부 서비스 및 처리 위치

Google Firebase의 Authentication은 익명 인증을, Cloud Firestore는 공유 정보 저장·조회를 담당합니다. Firebase 인증 서비스는 부정 사용 방지를 위해 IP 주소와 브라우저 정보 등을 처리할 수 있습니다. 별도의 광고·사용 분석 SDK는 앱에 포함하지 않습니다.

Firebase 공식 안내에 따르면 Authentication은 미국에서 처리됩니다. Firestore는 프로젝트에 설정된 위치를 사용하며 실제 운영 프로젝트의 위치는 공개 전 확인해야 합니다. 데이터 항목·처리 목적·보관 기간과 함께 국외 처리에 필요한 고지·동의 내용을 확정합니다.

Firebase 인증 계정은 앱 삭제와 함께 자동으로 삭제되지 않습니다. 운영자의 계정 삭제 절차 및 공급자의 삭제·백업 보관 정책이 적용됩니다. 웹페이지 열기는 해당 사이트에 직접 접속하는 동작이므로 해당 사이트의 개인정보 처리방침이 적용됩니다.

Firebase 개인정보 및 보안 안내

보관과 삭제

개인 작업공간은 사용자가 카드 메뉴에서 삭제할 수 있습니다. 삭제는 브라우저 탭이나 원본 파일을 삭제하지 않습니다. 확장앱 제거 시 브라우저가 앱의 로컬 저장소를 제거하며, 이것은 Firebase의 공유 문서나 익명 계정 삭제를 뜻하지 않습니다.

탭 실행 추적용 세션 정보는 브라우저 종료 또는 확장앱 다시 로드 시 초기화됩니다. 서버 공유 문서와 익명 계정은 각각 별도 삭제가 필요합니다. 문의 메일에도 개인 정보가 포함될 수 있으므로 처리 완료 후 보관·삭제 기준을 공개 전에 함께 확정합니다.

보호 조치와 변경 안내

서버 통신에는 HTTPS와 Firebase 인증 토큰을 사용합니다. Firestore 규칙은 전체 목록 조회와 공유본 수정을 차단하고, 유효기간 및 생성 데이터 형식을 확인합니다. 공유 코드와 주소를 전달할 상대는 신중하게 선택해 주세요.

이 안내는 현재 0.3.0 구현을 기준으로 작성했습니다. 공개 시 확정한 시행일과 변경 내용을 안내하며, 처리 목적·항목·보관 방법이 변경되면 안내와 실제 구현을 함께 갱신합니다.
