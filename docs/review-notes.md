# ME:WE 심사 설명 및 시험 방법

대상: **0.3.1 리뷰 반영 버전** · 2026-10-23 · 운영팀 ewhale / 개발자 정희진

## 앱 소개

학습에 쓰는 페이지들을 기기에 저장하고, 필요할 때 한꺼번에 다시 여는 웨일 사이드바 앱입니다. 웨일 듀얼탭의 좌우 구성도 복원합니다. 공유는 웹페이지 목록을 코드로 전달하는 보조 기능이며 실시간 공동 편집 기능은 아닙니다.

콘텐츠 스크립트, 외부 실행 코드, 광고·분석 SDK는 없습니다. 네이버 또는 이화여자대학교의 공식 앱이 아닙니다.

## 권한과 실제 사용

| 권한·호스트 | 사용 목적 |
| --- | --- |
| storage | 탭 모음·순서·공유 동의·인증의 로컬 저장, 실행 탭 추적·수신 미리보기의 세션 저장 |
| tabs | 현재 페이지 제목·URL 확인, 저장한 페이지 열기·닫기 |
| debugger | getTargets로 일반 탭 조회에 누락된 듀얼탭의 탭 ID 확인. attach·sendCommand 미사용 |
| clipboardWrite | 사용자가 요청한 공유 코드 복사 |
| clipboardRead | 사용자가 공유 코드 입력의 붙여넣기 버튼을 누를 때만 텍스트 읽기 |
| identitytoolkit.googleapis.com | Firebase 익명 인증 |
| securetoken.googleapis.com | 인증 토큰 갱신 |
| firestore.googleapis.com | 공유 문서 생성 및 코드별 조회 |

debugger는 듀얼탭 양쪽을 수집하기 위한 의존성입니다. 디버깅 세션을 연결하거나 페이지에 디버깅 명령을 보내지 않습니다. 웹사이트 전체에 대한 호스트 권한은 요청하지 않습니다. 붙여넣기는 코드 입력란만 채우며, ‘탭 불러오기’를 눌러 형식을 확인한 코드로만 서버를 조회합니다.

## 심사 시험 순서

1. ZIP을 풀어 새 웨일 프로필에 설치하고 사이드바에서 ME:WE를 엽니다. 별도 빌드·회원가입·사용자 Firebase 설정이 필요하지 않습니다.
2. 일반 웹페이지 3개 중 2개를 듀얼탭으로 구성합니다. **탭 저장하기**에서 양쪽 A/B 표시를 확인합니다. 한쪽만 해제하면 나머지가 선택된 채 일반 페이지로 저장됩니다.
3. 기본 선택 **새 탭 모음 만들기**에서 이름을 입력해 저장합니다. 다시 **탭 저장하기 → 기존 탭 모음에 추가하기**를 선택해 같은 모음 뒤에 추가되는지, 합계 10개를 초과하면 안내하고 저장하지 않는지 확인합니다. **탭 모음 열기**로 복원하고 **한 번에 닫기** 확인창의 취소·모두 닫기를 확인합니다. 닫기는 앱으로 연 탭만 닫고 기존 탭을 보존해야 합니다.
4. 카드 메뉴의 **수정**에서 링크를 입력한 뒤 Enter로 추가·저장합니다. 드래그 또는 Alt+↑/↓로 순서를 바꿉니다. **삭제** 후 확인창에서 취소하면 원본이 유지됩니다.
5. 공개 웹페이지 탭 모음의 **탭 모음 공유**를 누릅니다. 첫 이용 시 개인정보 수집·이용 및 국외 이전에 각각 동의한 뒤 코드를 생성·복사합니다. 화면을 열거나 체크만 할 때는 인증 요청을 보내지 않습니다. 복사 후 독립적인 복사본이며 수정사항이 자동 반영되지 않는다는 안내를 확인합니다.
6. 다른 프로필의 **공유 코드 입력**에서 **붙여넣기**로 코드가 채워지는지 확인합니다. 최초 동의를 완료하고 **탭 불러오기**를 누른 뒤 탭 모음 카드 형태의 미리보기에서 **저장** 또는 **바로 열기**를 확인합니다. 붙여넣기만으로는 서버를 조회하지 않으며 동일 브라우저에서 다음 공유·받기는 동의를 반복하지 않습니다.
7. 로컬 PDF를 포함한 탭 모음을 공유하면 파일은 제외됩니다. 웹페이지가 하나도 없으면 코드 생성이 비활성화됩니다. 파일 내용은 업로드하지 않으며 공유 전 로컬 파일·로그인·접근 권한·기기 환경에 따른 화면 차이를 안내합니다.
8. 앱 정보의 개인정보 처리방침·문의 주소·공유 사용 중지를 확인합니다. 사용 중지 후에는 다음 이용 시 다시 동의받습니다. 공유 장애가 발생해도 저장한 개인 탭 모음은 유지됩니다.

개인정보가 없는 공개 페이지로 새 코드를 생성해 시험하세요. 공유 코드는 7일 후 만료되므로 심사용 고정 코드는 제공하지 않습니다.

## 개인정보·운영

- 개인 탭 모음은 로컬에만 저장합니다. 공유 요청 시 미리보기의 이름·웹페이지 제목/URL·구성 등을 서버에 저장합니다.
- Firestore 서울 설정은 운영자가 확인했습니다. Authentication의 미국 처리는 별도로 고지하고 동의받습니다.
- 공유 코드는 7일 유효하며, 담당자가 매주 만료 문서를 정리해 생성 후 최대 14일 내 삭제합니다. 서버 자동 삭제는 없습니다.
- 공유 사용 중지는 로컬 동의·수신 미리보기를 지웁니다. 서버 공유본·익명 계정 삭제 요청은 담당자 이메일로 처리합니다.

## 알려진 범위

탭 모음당 최대 10페이지입니다. 로그인 세션·문서 접근 권한·스크롤 위치·파일 내용은 전달하지 않습니다. 듀얼탭 복원이 실패하면 일반 탭으로 열고 안내합니다. 재시작·확장앱 재로드 이전의 탭은 닫기 추적 대상이 아닙니다. 공유받아 바로 연 탭은 먼저 저장되며 해당 카드에서 닫을 수 있습니다. 다른 페이지와 수동 결합한 듀얼탭은 보호합니다.

받는 사람이 저장한 공유 복사본은 원본과 독립적입니다. 공유본 목록·서버 삭제를 위한 앱 내 UI는 현재 제공하지 않습니다.

시험 결과와 운영자가 확인할 사항은 [최종 검토 결과](final-review.md) 및 [제출 체크리스트](release-checklist.md)에 구분해 기록합니다.
