# ME:WE 구조와 권한

| 경로 | 역할 |
| --- | --- |
| sidebar.html / app.js | 사이드바·알림·기능 연결 |
| background.js | 저장 직렬 처리, 실행 탭 추적, 공유 인증·요청 |
| features/study-widget/ | 탭 모음·편집·재정렬·듀얼탭·닫기 |
| features/sharing/ | 코드 검증·REST 클라이언트·공유 화면 |
| features/about/ | 앱 정보·개인정보 안내 |
| shared/ | 브라우저 API·데이터 검증·저장소·스타일 |
| firestore.rules | 공유 데이터 접근·형식 검증 |

런타임은 ES 모듈이며 별도 빌드 없이 설치합니다. 외부 실행 스크립트와 콘텐츠 스크립트는 없습니다. Playwright·Java는 개발 검증용이며 배포 ZIP에 넣지 않습니다.

## 데이터 흐름

개인 탭 모음은 로컬에 저장합니다. 쓰기는 백그라운드에서 직렬 처리하고 수정 충돌을 검사합니다. 기존 모음에 추가할 때는 현재 저장된 페이지 뒤에 추가하고 합계 10페이지 제한을 검사합니다. 화면 명칭이 바뀌어도 기존 workspace 저장 키·데이터 형식은 유지합니다. 닫기는 URL 대신 생성한 탭 ID를 세션에 저장해 대상을 식별하며, 확인창에서 승인한 뒤 실행합니다.

공유는 사용자 요청 시 HTTP/HTTPS 페이지를 골라 익명 인증 후 문서를 생성합니다. 제외된 파일 이름·경로는 전송하지 않습니다. 받기는 정확한 코드만 조회하고 수신 데이터를 다시 검증합니다. 전체 공유 목록 조회와 수정은 규칙으로 차단합니다.

## 권한

| 권한 | 사용 목적 |
| --- | --- |
| storage | 개인 탭 모음·인증 정보, 실행·미리보기 세션 저장 |
| tabs | 제목·주소 확인, 탭 열기·닫기·이동 |
| debugger | 일반 조회에서 누락된 듀얼탭의 페이지 ID 확인 |
| clipboardWrite | 사용자가 요청한 공유 코드 복사 |
| clipboardRead | 공유 코드 입력의 붙여넣기 버튼을 누를 때 클립보드 텍스트 읽기 |
| Firebase API 3개 호스트 | 익명 인증·토큰 갱신·공유 저장·조회 |

debugger는 `getTargets` 조회에만 사용하며 `attach`·`sendCommand`는 사용하지 않습니다. 요청 권한은 실제 사용 범위보다 넓으므로 제출 설명에 필요성을 명시하고 대안을 검토합니다.

클립보드 텍스트는 명시적으로 붙여넣기를 요청한 시점에 입력란에만 표시합니다. 공유 조회는 ‘탭 불러오기’를 누른 뒤 형식이 검증된 코드로 수행합니다. 기존 최초 공유 동의 버전·범위는 유지합니다.

## 보안과 제한

- 무작위 12자리 코드는 목록 접근 수단이며 작성자 본인 확인 수단과 동일하지 않습니다.
- 7일 만료는 조회 차단이며 자동 삭제가 아닙니다.
- 인증 토큰은 로컬에 보관하고 공유 문서에는 넣지 않습니다.
- 공개 웹 설정은 서버 관리자 비밀키가 아닙니다. 서비스 계정 키를 앱에 넣지 않습니다.
- 익명 인증·규칙만으로 강력한 요청 속도 제한이 제공되지는 않습니다.
- 외부 데이터 검증과 텍스트 렌더링을 유지합니다.
