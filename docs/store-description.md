## 상세 설명 복사용

```text
하던 공부를 작업공간으로 저장하고, 필요할 때 다시 이어가세요.

ME:WE는 열어둔 학습 페이지를 묶어 저장하는 네이버 웨일 사이드바 확장앱입니다.

주요 기능
• 현재 창의 페이지를 선택해 작업공간으로 저장
• 작업공간 열기와 앱으로 연 페이지 닫기
• 웨일 듀얼탭의 좌우 페이지 구성 저장과 복원
• 카드 드래그로 순서 변경, 이름·페이지 목록 수정
• 로컬 PDF 등의 파일 주소 저장
• 12자리 공유 코드로 웹페이지 목록 공유 및 가져오기

사용 방법
1. 사이드바에서 ME:WE를 엽니다.
2. ‘지금 작업공간 저장’을 누르고 이름과 페이지를 선택합니다.
3. 저장한 카드에서 열기·닫기·공유를 사용합니다.
4. 받은 코드는 ‘공유 작업공간 받기’에 입력합니다.

데이터와 공유
개인 작업공간은 기기에 저장되며 자동 업로드하지 않습니다. 공유 코드 복사를 누르면 미리보기의 작업공간 이름과 웹페이지 정보 등을 Firebase에 저장합니다. 코드를 아는 사람은 유효기간 안에 목록을 확인할 수 있습니다. 웹 주소에 검색어·개인정보·비공개 문서 접근 정보가 포함되어 있는지 확인한 뒤 공유해 주세요.

공유 코드는 7일 동안 사용할 수 있습니다. 만료된 공유 자료는 담당자가 매주 정리하여 생성 후 최대 14일 이내 삭제합니다. 만료 즉시 자동 삭제되는 것은 아닙니다. 공유 기능은 최초 이용 시 개인정보 수집·이용 및 미국으로의 인증 정보 이전에 동의한 뒤 사용할 수 있습니다. 같은 브라우저에서는 반복 동의를 생략하며, 앱 정보에서 공유 사용을 중지할 수 있습니다. 동의하지 않아도 개인 작업공간 기능은 사용할 수 있습니다.

알아두세요
• 작업공간 개수에는 앱에서 정한 제한이 없으며 작업공간 하나에는 최대 10페이지를 저장할 수 있습니다.
• 로컬 파일은 경로만 저장합니다. 파일을 이동·삭제하면 다시 열 수 없으며 다른 사람에게 공유되지 않습니다.
• 로그인 상태와 문서 열람 권한은 전달되지 않습니다.
• 듀얼탭 복원이 불가능하면 일반 탭으로 열고 안내합니다.
• 닫기는 이번 브라우저 실행 중 앱이 추적한 탭에 적용됩니다. 브라우저 재시작 전의 탭과 공유받아 ‘바로 열기’한 탭은 저장된 카드의 닫기 대상이 아닙니다.
• 공유 기능에는 인터넷 연결이 필요합니다.
```
