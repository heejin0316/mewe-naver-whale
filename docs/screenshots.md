# ME:WE 스토어 스크린샷 준비

[웨일 등록 안내](https://developers.whale.naver.com/distribution/) 기준: 1280×800 JPG 또는 PNG, 최소 1장·최대 4장. 아이콘은 128×128 PNG입니다.

## 권장 4장

1. **작업공간 목록**: 카드 아래 열기·공유, 드래그로 순서 변경을 보여줍니다.
2. **현재 페이지 저장**: 일반 페이지와 듀얼탭 A/B가 함께 나오는 저장 화면을 보여줍니다.
3. **공유 미리보기**: 공유할 웹페이지와 로컬 파일 제외 안내를 보여줍니다. 실제 코드를 발급하기 전 화면을 사용합니다.
4. **공유받기**: 미리보기와 저장·바로 열기 버튼을 보여줍니다. 테스트 자료만 사용합니다.

## 촬영 방법

최종 패키지를 별도 웨일 테스트 프로필에 설치합니다. 공개 테스트 페이지로 ‘논문 읽기’, ‘수업 자료’ 등 예시 작업공간을 구성하고 실제 앱을 캡처합니다. 1280×800 화면에서 사이드바를 적절히 펼치되 사용자가 오해할 합성 기능이나 가짜 상태를 추가하지 않습니다.

실제 계정명, 프로필 사진, 이메일, 포털 학번, 파일 경로, 접근 토큰, 개인 검색어와 유효한 공유 코드를 노출하지 않습니다. 예시 데이터임을 설명에 명시할 수 있습니다. 넓은 화면으로 UI를 억지로 늘리거나 과거 버전 사진을 사용하지 않습니다.

## 파일 위치와 상태

- 아이콘 원본: `assets/icons/icon128.png`.
- 기존 개발 검증 캡처: `test-results/`. 좁은 화면과 모의 데이터가 포함되어 있어 최종 제출 규격을 충족한 것으로 취급하지 않습니다.
- 최종 촬영 결과: 포장 결과의 별도 `screenshots/` 폴더에 저장합니다. 현재 최종 제출용 4장은 미촬영입니다.

촬영은 개인정보와 운영 정책 보완 후 최신 UI를 기준으로 진행합니다.
