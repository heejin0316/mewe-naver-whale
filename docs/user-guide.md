# ME:WE 사용 가이드

## 설치와 업데이트

데스크톱 웨일에서 [앱 ZIP](../delivery/MEWE-0.3.1.zip)을 풀고 `whale://extensions`의 개발자 모드에서 `manifest.json`이 있는 폴더를 설치합니다. [설치 순서](../README.md)

업데이트할 때는 같은 폴더의 파일을 갱신하고 확장앱 관리에서 새로고침합니다. 앱을 제거하면 로컬 데이터가 사라질 수 있습니다. 다른 폴더를 새로 설치하면 기존 데이터가 자동으로 이어진다고 보장할 수 없습니다.

## 만들기와 링크 추가

현재 창에 필요한 페이지를 열고 **탭 저장하기**를 누릅니다. 포함할 페이지를 선택한 다음 **어디에 저장할까요?**에서 저장 위치를 고릅니다.

- 기본 선택인 **새 탭 모음 만들기**에서는 이름을 입력합니다.
- **기존 탭 모음에 추가하기**에서는 이름 목록에서 기존 탭 모음을 선택합니다. 선택한 페이지를 기존 목록 뒤에 추가하며 같은 주소도 별도 페이지로 추가할 수 있습니다. 기존 페이지와 합쳐 10개를 넘으면 저장하지 않고 안내합니다.

**저장**하면 선택한 위치에 반영됩니다. 저장한 목록은 **저장한 탭 관리**에서 확인합니다.

듀얼탭은 A가 왼쪽, B가 오른쪽입니다. 각 페이지를 개별 선택·해제할 수 있습니다. 한쪽만 선택하면 듀얼탭 표시가 사라지고 선택한 쪽은 일반 페이지로 저장됩니다. 저장 전에 양쪽을 다시 선택하면 A/B 표시와 듀얼탭 구성이 복원됩니다. 탭 모음당 최대 10페이지이며 듀얼탭은 두 페이지로 셉니다. 탭 모음 개수 제한은 없습니다.

**링크 직접 추가 → 주소 입력 → Enter**로 목록에 넣습니다. 이름이 입력되어 있으면 저장 버튼으로 초점이 이동하고 **Enter를 다시 누르면 저장**됩니다. 이름이 비어 있으면 이름 입력란으로 이동합니다. 버튼 클릭도 가능합니다.

웹 주소 또는 `file:///C:/자료/강의.pdf`, `C:\자료\강의.pdf` 같은 경로를 사용할 수 있습니다. 파일 내용은 복사하지 않습니다. 파일을 이동·삭제하면 경로를 수정해야 합니다.

## 열기와 닫기

**한 번에 열기**를 누르면 페이지가 열리고 왼쪽 버튼이 **한 번에 닫기**로 바뀝니다. 누르면 확인창에서 안내를 읽고 **취소** 또는 **모두 닫기**를 선택합니다. 닫기는 생성한 탭 ID로 동작해 같은 주소의 기존 탭을 임의로 닫지 않습니다. 브라우저 재시작·확장앱 재로드 전의 탭은 추적 대상이 아닙니다.

다른 페이지와 수동 결합한 듀얼탭은 함께 닫히지 않도록 보호합니다. 분리한 후 다시 닫아 주세요. 듀얼탭 복원 실패 시 일반탭으로 열고 안내합니다.

## 수정과 정렬

**저장한 탭 관리**를 누르면 카드에 **수정·삭제** 버튼이 나타납니다. **관리 완료**로 열기·공유 버튼 화면에 돌아갑니다. 수정 화면의 페이지 `⋮ → 탭 모음에서 제거`는 저장할 때 반영됩니다. 듀얼탭 한쪽을 제거하면 남은 쪽은 일반탭으로 저장됩니다. 모든 페이지를 제거한 빈 탭 모음은 저장되지 않습니다.

탭 모음 전체를 삭제할 때는 확인창에서 **삭제**를 눌러야 반영됩니다. 취소하면 그대로 유지됩니다. 삭제는 되돌릴 수 없으며 이미 열어둔 페이지나 전달한 공유본에는 영향을 주지 않습니다.

카드 제목·빈 공간을 잡아 드래그하거나 카드에 초점을 둔 채 **Alt + ↑ / ↓**로 순서를 변경합니다. 드래그 중 Escape로 취소할 수 있습니다.

## 공유와 받기

**탭 모음 공유**에서 목록과 전달 전 안내를 확인하고 **공유 코드 복사**를 누릅니다. 로컬 파일은 제외되며 한쪽만 남은 듀얼탭은 일반탭으로 전달됩니다. 로그인·접근 권한이 필요한 페이지나 기기별 주소는 받는 사람에게 같은 화면으로 열리지 않을 수 있습니다. 원본은 바뀌지 않습니다.

복사 후에는 “공유된 탭 모음은 독립적인 복사본입니다. 이후 수정사항은 자동으로 반영되지 않아요.” 안내가 표시됩니다.

최초 이용 시 개인정보 수집·이용과 국외 이전에 각각 동의합니다. 같은 브라우저의 공유하기·받기에 공통 적용되며, 앱 정보에서 공유 사용을 중지하거나 동의 범위가 바뀌면 다시 동의받습니다.

코드는 12자리이며 생성 후 7일 동안 유효합니다. 로그인·열람 권한은 전달되지 않습니다. URL에 개인정보나 비공개 접근 정보가 없는지 확인하세요. 공유할 페이지를 빼려면 현재는 원본 탭 모음을 수정해야 합니다.

**공유 코드 입력**에서 코드를 직접 입력하거나 입력란 옆 **붙여넣기**를 누릅니다. 붙여넣기는 기기의 입력란만 채우며 **탭 불러오기**를 눌러야 코드를 조회합니다. 클립보드 내용을 자동으로 수집하거나 공유하지 않습니다.

불러온 탭 모음은 저장한 탭 모음과 같은 카드 형태로 표시됩니다. **저장**은 독립적인 복사본을 저장하고, **바로 열기**는 먼저 저장한 뒤 페이지를 엽니다. 저장에 실패하면 탭을 열지 않고 오류를 안내합니다. 바로 열기로 연 탭도 저장된 카드에서 한 번에 닫을 수 있습니다.

만료된 서버 데이터는 자동 삭제되지 않습니다. 저장한 탭 모음 삭제와 서버 공유본 삭제도 별개입니다. [개인정보 안내](../PRIVACY.md)

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 설치가 안 됨 | ZIP을 먼저 풀고 manifest.json이 있는 폴더 선택 |
| 코드 오류 | 코드 오타·7일 유효기간·인터넷 연결 확인 |
| 로그인 화면이 표시됨 | 받는 사람의 사이트 계정으로 로그인 필요 |
| PDF가 안 열림 | 같은 컴퓨터에 파일이 있고 경로가 바뀌지 않았는지 확인 |
| 복사 실패 | 표시된 코드를 선택해 Ctrl+C로 복사 |
| 붙여넣기 실패 | 코드 입력란에 Ctrl+V로 붙여넣거나 직접 입력 |
| 모든 공유가 실패 | 서비스 장애·한도일 수 있으므로 문의. Firebase 직접 설정 불필요 |
