# ME:WE 사용 가이드

## 설치와 업데이트

데스크톱 웨일에서 저장소 ZIP을 풀고 `whale://extensions`의 개발자 모드에서 `manifest.json`이 있는 폴더를 설치합니다. [설치 순서](../README.md)

업데이트할 때는 같은 폴더의 파일을 갱신하고 확장앱 관리에서 새로고침합니다. 앱을 제거하면 로컬 데이터가 사라질 수 있습니다. 다른 폴더를 새로 설치하면 기존 데이터가 자동으로 이어진다고 보장할 수 없습니다.

## 만들기와 링크 추가

현재 창에 필요한 페이지를 열고 **지금 작업공간 저장**을 누릅니다. 이름과 페이지를 선택한 뒤 저장합니다. **새 작업공간**에서도 현재 페이지를 가져오거나 링크를 추가할 수 있습니다.

듀얼탭은 A가 왼쪽, B가 오른쪽입니다. 함께 선택·해제하며 두 페이지로 셉니다. 작업공간당 최대 10페이지이고 작업공간 개수 제한은 없습니다.

**링크 직접 추가 → 주소 입력 → Enter**로 목록에 넣습니다. 이름이 입력되어 있으면 저장 버튼으로 초점이 이동하고 **Enter를 다시 누르면 저장**됩니다. 이름이 비어 있으면 이름 입력란으로 이동합니다. 버튼 클릭도 가능합니다.

웹 주소 또는 `file:///C:/자료/강의.pdf`, `C:\자료\강의.pdf` 같은 경로를 사용할 수 있습니다. 파일 내용은 복사하지 않습니다. 파일을 이동·삭제하면 경로를 수정해야 합니다.

## 열기와 닫기

열기를 누르면 페이지가 열리고 왼쪽 버튼이 닫기로 바뀝니다. 닫기는 생성한 탭 ID로 동작해 같은 주소의 기존 탭을 임의로 닫지 않습니다. 브라우저 재시작·확장앱 재로드 전의 탭은 추적 대상이 아닙니다.

다른 페이지와 수동 결합한 듀얼탭은 함께 닫히지 않도록 보호합니다. 분리한 후 다시 닫아 주세요. 듀얼탭 복원 실패 시 일반탭으로 열고 안내합니다.

## 수정과 정렬

카드 `⋮`에서 수정·삭제합니다. 수정 화면의 페이지 `⋮ → 작업공간에서 제거`는 저장할 때 반영됩니다. 듀얼탭 한쪽을 제거하면 남은 쪽은 일반탭으로 저장됩니다. 모든 페이지를 제거한 빈 작업공간은 저장되지 않습니다.

카드 제목·빈 공간을 잡아 드래그하거나 카드에 초점을 둔 채 **Alt + ↑ / ↓**로 순서를 변경합니다. 드래그 중 Escape로 취소할 수 있습니다.

## 공유와 받기

**작업공간 공유**에서 목록을 확인하고 **공유 코드 복사**를 누릅니다. 로컬 파일은 제외되며 한쪽만 남은 듀얼탭은 일반탭으로 전달됩니다. 원본은 바뀌지 않습니다.

코드는 12자리이며 생성 후 7일 동안 유효합니다. 로그인·열람 권한은 전달되지 않습니다. URL에 개인정보나 비공개 접근 정보가 없는지 확인하세요. 공유할 페이지를 빼려면 현재는 원본 작업공간을 수정해야 합니다.

**공유 작업공간 받기**에 코드를 넣고 확인합니다. **저장**은 독립적인 복사본을 만들고 **바로 열기**는 저장 없이 실행합니다. 바로 열기로 연 탭은 저장된 카드의 닫기 대상이 아닙니다.

만료된 서버 데이터는 자동 삭제되지 않습니다. 내 작업공간 삭제와 서버 공유본 삭제도 별개입니다. [개인정보 안내](../PRIVACY.md)

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 설치가 안 됨 | ZIP을 먼저 풀고 manifest.json이 있는 폴더 선택 |
| 코드 오류 | 코드 오타·7일 유효기간·인터넷 연결 확인 |
| 로그인 화면이 표시됨 | 받는 사람의 사이트 계정으로 로그인 필요 |
| PDF가 안 열림 | 같은 컴퓨터에 파일이 있고 경로가 바뀌지 않았는지 확인 |
| 복사 실패 | 표시된 코드를 선택해 Ctrl+C로 복사 |
| 모든 공유가 실패 | 서비스 장애·한도일 수 있으므로 문의. Firebase 직접 설정 불필요 |
