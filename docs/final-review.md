# ME:WE 버전별 검토 결과

## 0.3.1 리뷰 반영 — 2026-10-23

추가 피드백 반영: 링크 추가 버튼을 우측 하단에 작게 배치하고, 관리 모드에 수정·삭제 버튼을 표시했습니다. 복사 알림은 두 줄과 첫 문장 강조로 표시합니다. 공유 미리보기의 바로 열기는 먼저 저장한 모음을 실행합니다. UI 회귀 시험에서 관리 모드 전환, 저장 실패 시 실행 차단, 저장 성공 후 저장된 ID로 실행을 확인했고 단위 시험 33개를 다시 통과했습니다.

화면 명칭, 새/기존 탭 모음 저장 위치, 한 번에 닫기 확인, 공유 전 안내·복사 후 알림, 공유 코드 붙여넣기·미리보기를 갱신했습니다. 기존 데이터 형식과 최초 공유 동의 범위는 유지합니다. 관리 모드에는 수정·삭제 버튼을 직접 표시하고, 기본 카드의 메뉴에서도 같은 기능을 제공합니다.

제출 자료는 0.3.1 화면으로 다시 촬영했습니다. 공개 개인정보 페이지에는 이번 클립보드 읽기 안내가 게시되어야 하므로 GitHub 업로드 후 공개 URL의 갱신을 별도로 확인합니다.

아래는 **0.3.0의 이전 검증 기록**이며, 0.3.1에서 해당 시험을 모두 재실행했다는 의미가 아닙니다.

## 0.3.0 검증 기록

검토일: **2026-10-16** · 대상: **MEWE-0.3.0.zip** · 상태: **코드·설치 패키지 검증 완료, 스토어 미제출**

## 결론

현재 소스의 저장·수정·삭제·정렬·열기·닫기·듀얼탭·파일·공유 동작과 설치 패키지를 검증했습니다. 아래 운영 확인을 마친 뒤 네이버 담당자 최종 리뷰와 스토어 심사를 진행할 수 있습니다. 자동 시험 결과를 운영 서버 설정 확인이나 스토어 승인으로 해석하지 않습니다.

## 이번 정리

- 작업공간 삭제에 확인창을 추가하고, 취소·삭제 실패 시 원본 보존을 확인했습니다.
- 공유 오류 문구에서 사용자가 이해하기 어려운 서버 설정 지시를 제거했습니다.
- 실행 코드 문법 검사, ZIP과 소스 전체 파일 대조, 아이콘·스크린샷 규격·전달 파일 해시 검사를 추가했습니다.
- GitHub Actions에서 단위 시험·소스 점검·전달 파일 검증을 실행하도록 구성했습니다.
- 예전 미완료 상태와 해시가 섞인 문서를 현재 상태로 갱신했습니다. 과거 기록은 Git 이력에 보존됩니다.

## 제출 전 운영자가 확인할 것

1. **Firebase 콘솔**: 저장소 firestore.rules와 실제 게시 규칙 일치, 익명 인증 설정·사용량 확인. 두 사용자 공유 성공만으로 모든 규칙이 맞다고 판단하지 않습니다.
2. **삭제 업무 첫 실행**: 만료 문서 주간 정리로 최대 14일 보관을 지킬 수 있는지, 요청자 확인 후 공유본·익명 계정을 삭제하고 답변하는 절차를 실제 콘솔에서 검증합니다. 담당: 정희진. [운영 절차](operations.md)
3. **최종 리뷰·제출**: 네이버 담당자 리뷰, 브랜드·명칭 사용 권리 최종 확인, 스토어 공개 범위·입력 자료 확인 후 담당자가 심사를 요청합니다.

위 사항을 이번 작업에서 콘솔 실행·승인 완료로 표시하지 않았습니다. 서버 자동 삭제·예약 업무는 생성하지 않았습니다.

## 남겨 둔 개선 과제

- 밝은 그라데이션의 흰 글자 대비 개선: 현재 확정한 디자인은 유지했습니다. 접근성 적합 판정을 받은 상태는 아닙니다.
- 공유본 목록·철회 UI, 공유 전 페이지 개별 제외, 더 작은 권한으로 듀얼탭을 수집할 수 있는지 검토
- 공유 남용·무료 한도 소진 대응 강화

미구현 기능을 현재 기능으로 소개하지 않습니다. 알려진 제품 범위는 [사용 가이드](user-guide.md), 심사 순서는 [심사 설명](review-notes.md)을 확인하세요.
